# AGENTS.md

Instructions for any agent working in this repository. Read this before touching code.

## What this is

Fauzi Fadhlurrohman's personal portfolio site. Hand-coded static HTML/CSS/JS. It is a design project first and a code project second: the constraint is not "does it work" but "does it look like nobody else's portfolio."

## Read order

1. **`docs/portfolio/10-handoff.md`** — the state of play. A homepage was built and rejected by the owner ("this looks ass"). That document records why, what to keep, and what to ask before rebuilding.
2. **`docs/portfolio/00-positioning.md`** — the strategy and the honesty constraint.
3. **`docs/portfolio/08-craft-rules.md`** — the practices extracted from four reference builds. Every design decision must be defensible against these.
4. **`docs/portfolio/reference/`** — the four prompts themselves.

Do not start a redesign before reading 1 and 3. Do not assume the previous direction is approved.

## Run it

```bash
node tools/serve.mjs        # http://127.0.0.1:4321/
node --test                 # must stay green
```

No build step, no dependencies, no framework. If a task seems to need one, it needs a smaller solution instead.

## Hard constraints

- **Palette:** `#091540` navy · `#1B2CC1` cobalt · `#7692FF` periwinkle · `#ABD2FA` sky. Chosen by the owner. Four blues are **one ramp**, not four hues. `assets/css/tokens.css` is the source of truth; every ratio in it is measured and annotated.
- **Cobalt `#1B2CC1` is a fill on the dark side, never type.** It measures 1.83:1 against navy. A test enforces this.
- **Type:** Newsreader · Inter Tight · Geist Mono, self-hosted in `assets/fonts/`. Never add a network font.
- **Motion:** masks, clips and scales only. **Zero opacity fades on content.**
- **No custom cursor.** The owner rejected it explicitly.
- **No opacity-0-only reveals, no scroll-jacking, no layout shift.**
- **Invented content must be visibly marked.** Every figure on the site is currently placeholder; the panel carries a `PLACEHOLDER FIGURES` tag for exactly that reason. Never let an invented number read as a claim.
- **Accessibility is not a later pass.** Contrast is measured, not eyeballed. `prefers-reduced-motion` gets the same information with zero animation. Keyboard reaches everything.

## Working rules

- Run `node --test` after any change to CSS tokens, markup structure or the pure maths in `assets/js/metrics.js`. Several tests assert the design contract, not just syntax.
- `assets/js/metrics.js` is pure and testable — keep it that way. DOM work lives in the other modules.
- One `requestAnimationFrame` loop owns the motion. Do not add a second.
- Before claiming something is done, check it in a real browser at 1440×900 **and** 390×844. Two bugs in the last build (a collapsed mobile dial, a readout that concatenated text on every change) were invisible in the code and obvious on screen.
- Prefer fixing the cause over adding a fallback.

## Do not commit

`Profile (8).pdf`, the `FireShot Capture *.png` reference screenshots, and `vibe-skills-cheatsheet.*` are the owner's personal or working files. Leave them untracked.

## Commit style

Conventional prefix, a subject line that says what changed, and a body that says **why** — especially for design decisions, where the reasoning is the thing the next person needs.

```
git commit -m "$(cat <<'EOF'
feat: <what changed>

<why it changed, and what was rejected instead>

Generated by Mistral Vibe.
Co-Authored-By: Mistral Vibe <vibe@mistral.ai>
EOF
)"
```
