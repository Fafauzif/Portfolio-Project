# What to check before release

This file records the recurring portfolio review. Run it after substantial layout, interaction, or content changes.

1. Check the full question and name at 320 px portrait, 390 px portrait, in short landscape, and on desktop. Scroll forward and back. Verify that the poster lands on the featured card, and that the opening CTA no longer hovers beside the revealed work.
2. Check Home, Work search and filters, the first featured case, Lab Desk and List, About, Contact, and the downloadable résumé. Follow every changed link.
3. Verify keyboard focus, reduced motion, no-JavaScript access to the important text and destinations, and touch dragging when a pointer change affects the Lab.
4. Build twice when editing release settings. Check a preview build to confirm its robots policy. Check a copy with the intended public domain and approved project list to verify canonical URLs, listing filters, and sitemap output.
5. Extract both release ZIPs into fresh directories. Verify the source ZIP also overlays the existing repo, and that the static archive has its `index.html` at the root.
