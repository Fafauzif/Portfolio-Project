## The one-paragraph version

A third-year English Literature student at Universitas Indonesia who is really a marketing strategist: he writes the 32-page strategy, runs the campaign, measures it against a baseline he set himself, and when the tool he needs doesn't exist he codes it. The site claims the **strategist** category, proves it with a measured cause-and-effect chain, and treats his five competition placings as the rare assets they are — five pages, not five bullets.

Built to the craft rules extracted from four reference builds (`08`), on hand-coded static HTML. Mobile-first, because the audience will read it on a phone on 4G.

## Decisions locked

- **Goal:** hire-first, with a credible path for consulting work
- **Scope:** multi-page. Case-study pages at their own URLs; the homepage is the first build
- **Stack:** hand-coded static HTML/CSS/JS, no framework, no build step, GitHub Pages
- **Positioning line:** *"I don't stop at the deck."*
- **Palette:** `#091540` navy · `#1B2CC1` cobalt · `#7692FF` periwinkle · `#ABD2FA` sky — **chosen by Fauzi; keep unless he says otherwise.** Four blues are one ramp, not four hues
- **Type:** Newsreader (serif) · Inter Tight (grotesque) · Geist Mono (data), all self-hosted
- **Motion law:** masks and clips only — **zero opacity fades on content**
- **No custom cursor** (explicitly rejected)
- **Content:** placeholders ship first; every invented figure must be visibly marked
