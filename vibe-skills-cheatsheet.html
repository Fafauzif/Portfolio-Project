~/.vibe/skillsglobal scope

How to use one. Type /skill-name in chat, for example /impeccable or /grill-me. All 107 are user-invocable.

They also load themselves. Each description is routing text, so the right skill is picked up from what you ask, without a command.

After any install or edit, run /reload so the session picks up the change.
